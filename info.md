# Windows Direct Agent

Conecta y controla tu PC con Windows directamente desde Home Assistant con una aplicación de escritorio nativa ElectroBun de alto rendimiento.

## Características
- **19+ Sensores Inteligentes**: CPU, RAM, Disco, GPU, Batería, App Activa, Información Multimedia, Micrófono, Presencia y Red.
- **Controles Nativos**: Apagar, Reiniciar, Suspender, Bloquear, Volumen Maestro, Silencio y Captura de Pantalla.
- **Servicios Interactivos**: Notificaciones emergentes Windows (Toast) y Diálogo de Confirmación Glassmorphic.
- **Cero MQTT**: Conexión directa punto a punto LAN.
